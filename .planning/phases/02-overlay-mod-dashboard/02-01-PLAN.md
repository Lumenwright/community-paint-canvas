```typescript
// Shared stroke renderer -- used by overlay, mod dashboard preview, and Phase 4 StrokePreview.
// Renders stroke data onto any 2D canvas context (including OffscreenCanvas).

export interface Point {
  x: number;
  y: number;
}

export function renderStrokes(
  ctx: CanvasRenderingContext2D | OffscreenCanvasRenderingContext2D,
  strokes: Point[],
  lineWidths: number[],
  color: string = 'white'
): void {
  ctx.lineCap = 'round';
  ctx.lineJoin = 'round';
  for (let i = 1; i < strokes.length; i++) {
    const path = new Path2D();
    path.moveTo(strokes[i - 1].x, strokes[i - 1].y);
    path.lineTo(strokes[i].x, strokes[i].y);
    ctx.lineWidth = lineWidths[i] ?? lineWidths[0] ?? 7;
    ctx.strokeStyle = color;
    ctx.stroke(path);
  }
}
```

**web/src/lib/canvas/computeAlpha.ts:**
```typescript
// Client-side alpha fading -- derives opacity from timestamps + grace_seconds.
// No backend writes. Called every rAF frame for each cached bitmap.
// Per D-07: alpha is computed entirely client-side from timestamps.

export function computeAlpha(
  approvedAt: Date,
  expiresAt: Date | null,
  graceSeconds: number
): number {
  if (expiresAt === null) return 1.0; // grace_seconds = 0 means never fades
  const now = Date.now();
  const graceEnd = approvedAt.getTime() + graceSeconds * 1000;
  const fadeEnd = expiresAt.getTime();
  if (now < graceEnd) return 1.0;
  if (now >= fadeEnd) return 0.0;
  return 1.0 - (now - graceEnd) / (fadeEnd - graceEnd);
}
```

Both files use `.js` import extensions per project convention. The `Point` interface and `renderStrokes` function signature must match exactly as shown -- Phase 4's `StrokePreview.svelte` will import them. The `color` parameter defaults to `'white'` since the color schema field is not added until Phase 3 (SCHEMA-01/02).

Create `web/src/routes/overlay/+page.svelte` -- the OBS browser source overlay page.

This is a single-file Svelte 5 component with no `+page.server.ts` (no auth required -- overlay is public).

**Architecture (per D-04, D-05, D-06, D-07, D-08, D-09):**

1. **State:**
   - `let canvas: HTMLCanvasElement;` (plain let, NOT $state -- bind:this does not work with $state proxy)
   - `let graceSeconds = $state(1200);` -- default, updated by settings Realtime
   - `let fadeSeconds = $state(300);` -- default, updated by settings Realtime
   - `let bitmaps = $state(new Map<string, CachedDrawing>());` -- keyed by `drawings.id` UUID (CRITICAL: not entry_id, because DELETE payload with RLS only contains the primary key `id`)

2. **CachedDrawing interface:**
   ```typescript
   interface CachedDrawing {
     bitmap: ImageBitmap;
     approvedAt: Date;
     expiresAt: Date | null;
   }
   ```

3. **rAF render loop (in $effect):**
   - Access `canvas` inside `$effect` (guaranteed to be set after DOM paint)
   - `const ctx = canvas.getContext('2d')!;`
   - Each frame: `ctx.clearRect(0, 0, canvas.width, canvas.height)` (clearRect, NOT fillRect -- transparent bg per D-08)
   - Iterate `bitmaps.values()`: compute `alpha = computeAlpha(drawing.approvedAt, drawing.expiresAt, graceSeconds)`, skip if alpha <= 0, set `ctx.globalAlpha = alpha`, `ctx.drawImage(drawing.bitmap, 0, 0)`
   - Reset `ctx.globalAlpha = 1` after loop
   - Return cleanup: `cancelAnimationFrame(frame)`

4. **Realtime subscriptions + initial load (in onMount):**
   - Create ONE channel `supabase.channel('overlay')` with THREE `.on()` listeners chained before `.subscribe()`:
     a. `postgres_changes` INSERT on `drawings`: render strokes to OffscreenCanvas via `renderStrokes(octx, row.strokes, row.line_widths, 'white')`, call `createImageBitmap(offscreen)`, add to `bitmaps` Map keyed by `row.id`
     b. `postgres_changes` DELETE on `drawings`: call `bitmaps.delete(payload.old.id)` -- payload.old only has `{ id }` due to RLS
     c. `postgres_changes` UPDATE on `settings`: check `payload.new.key` -- if `'grace_seconds'` update `graceSeconds`, if `'fade_seconds'` update `fadeSeconds`

   - **Disconnect watchdog (per D-04):** In `.subscribe((status) => ...)`:
     - On `'SUBSCRIBED'`: clear any existing disconnect timer
     - On `'CHANNEL_ERROR'`, `'TIMED_OUT'`, `'CLOSED'`: start a 60-second timer that calls `location.reload()`. Only start if no timer already running. No visible indicator on stream.

   - **Initial load (per D-05):** After subscribing, load existing drawings via `supabase.from('drawings').select('*')` (anon-key query, RLS allows public reads). For each row, render to OffscreenCanvas and cache bitmap. Also load settings: `supabase.from('settings').select('*')` and extract `grace_seconds` and `fade_seconds` values.

   - Return cleanup: clear disconnect timer, call `supabase.removeChannel(channel)`

5. **Canvas sizing:** Set `canvas.width` and `canvas.height` to `window.innerWidth` and `window.innerHeight` on mount. Listen for `resize` event and update dimensions (also rebuild all bitmaps since OffscreenCanvas dimensions change).

6. **Template:**
   ```svelte
   <canvas bind:this={canvas}></canvas>
   ```

7. **Styles (scoped + global):**
   ```svelte
   <style>
     :global(html), :global(body) {
       background: transparent;
       margin: 0;
       overflow: hidden;
     }
     canvas {
       position: fixed;
       inset: 0;
       width: 100vw;
       height: 100vh;
     }
   </style>
   ```

**Helper function for bitmap creation (inside the component):**
```typescript
async function createCachedDrawing(
  row: { id: string; strokes: Point[]; line_widths: number[]; approved_at: string; expires_at: string | null },
  canvasWidth: number,
  canvasHeight: number
): Promise<[string, CachedDrawing]> {
  const offscreen = new OffscreenCanvas(canvasWidth, canvasHeight);
  const octx = offscreen.getContext('2d')!;
  renderStrokes(octx, row.strokes, row.line_widths, 'white');
  const bitmap = await createImageBitmap(offscreen);
  return [row.id, {
    bitmap,
    approvedAt: new Date(row.approved_at),
    expiresAt: row.expires_at ? new Date(row.expires_at) : null
  }];
}
```
